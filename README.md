# 青情暖夕阳 · 网页 App 演示版

依据 `青春暖夕阳app.pdf` 的精神陪伴、社区、健康记录、亲友联络和青年志愿服务构想制作。针对护理仿真创新应用赛道，加入了“独居老人情绪变化与沟通”情境仿真，供参赛展示护理沟通、风险识别和转介决策流程。

## 运行

在本目录执行：

```sh
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000`。也可以直接打开 `index.html`。无需安装依赖或联网。

## 推送到 GitHub 并发布网页

本目录的 `.gitignore` 已排除策划 PDF 和比赛通知网页及其附件。仓库中只需保留网页 App 文件、README、`.gitignore` 和 `.nojekyll`。

1. 在 GitHub 创建一个**空仓库**，不要勾选自动生成 README、`.gitignore` 或 License。
2. 在本目录执行以下命令，将占位符替换为自己的 GitHub 用户名和仓库名：

```sh
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main
```

3. 在仓库页面打开 **Settings → Pages**，选择 **Deploy from a branch**，分支选 `main`，文件夹选 `/(root)`，然后保存。站点地址通常是 `https://你的用户名.github.io/你的仓库名/`。

后续修改可在本目录执行 `git add index.html styles.css app.js README.md`、`git commit -m "Update app"`、`git push`。GitHub Pages 是公开网页；不要上传真实长者的身份或健康信息。

## 演示路径

1. 选择“长者”，完成心情签到、发出陪伴请求、记录健康状况，并查看亲友留言。
2. 通过右上角切换到“志愿者”，查看请求并接受，进入“沟通仿真”完成三轮选择、查看反馈和成绩。
3. 切换到“亲友”，查看长者主动共享的签到及记录，并发送留言；再切回长者查看。
4. 社区页面可以发布动态并点赞。数据存储于当前浏览器的 `localStorage`，刷新后保留；“重置演示数据”可恢复初始状态。

## 演示边界

这是单机交互原型。页面中的长者、亲友、志愿者共用一台设备上的演示数据，没有账号认证、远程同步、真实匹配、医疗诊断、心理咨询、紧急救援或支付能力。健康数值仅用于记录，不据此作诊断或自动报警。正式上线前需要身份与资质核验、隐私授权、数据安全、专业人员值守及线下服务机制。

策划案中的商城、会员代币和微信公众号推送需要经营资质、第三方平台接入及持续运营，因此没有伪装成已实现的功能。比赛通知建议提交作品方案 PDF、3～5 分钟 MP4 视频、答辩 PPT 或作品成果；本项目是可现场展示的作品成果原型，并不替代其他申报材料。
